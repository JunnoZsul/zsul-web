Cómo calculamos

El precio base se ajusta por volumen y complejidad.

Registros

La base considera hasta 50,000 registros. Cada bloque adicional de 50,000 registros puede sumar desde $1,000 MXN.

Fuentes de datos

El dashboard base incluye 1 fuente. Cada fuente adicional puede sumar desde $1,500 MXN según el formato o conector.

Vistas y KPIs

Una vista adicional de dashboard puede sumar desde $2,500 MXN, dependiendo de filtros, métricas y nivel visual.

Automatización

APIs, conexiones especiales o actualizaciones frecuentes se cotizan según el sistema y la frecuencia requerida.

Ajustes y urgencia

Rondas extra de cambios o entregas urgentes pueden modificar el precio final del proyecto.
